# Dumjosh — Premium Restaurant Website

A bespoke, luxury editorial restaurant website for **Dumjosh** (located at Sector 104, Noida, Uttar Pradesh, India), communicating its modern Indian culinary identity, progressive Asian influences, regional depth (Vidarbha Saoji, Mangalore Ghee Roast, Awadh, Old Delhi), and energetic hospitality.

Designed strictly in accordance with the **Dumjosh Brand Book 2026**, the official **Dumjosh Menu**, and corporate **Dumjosh Food Packages**.

---

## 🍽️ Features

- **Editorial Luxury Design**: Tailored luxury color palette (`#4A1820` burgundy, `#7A4B34` terracotta, `#F4EDE2` parchment, `#211C19` ebony, `#B7955B` antique gold) and typography (**Cormorant Garamond**, **Playfair Display**, **Manrope**).
- **Authentic Brand Photography**: Authentic photography extracted directly from official brand collateral.
- **10-Section Homepage**:
  - Fullscreen cinematic hero with royal typography.
  - Split editorial **DUM + JOSH** philosophy.
  - Showstopper signature dishes.
  - 6 Interactive Culinary Worlds (Biryani & Dum, Regional Indian, Asian Favourites, Tandoor & Grill, Slow-Cooked Curries, The Celebration Table).
  - 4 Dining Occasions (Quick Coffee, Leisurely Meals, Corporate Dining, Special Celebrations).
  - Celebrations & Private Dining feature.
  - Corporate Dining highlights.
  - Horizontal scrolling visual gallery.
  - Verified local diner reflections.
  - Location, driving directions, and interactive Google Map.
- **Interactive Menu Explorer (`/menu`)**:
  - All 12 verified categories and 60+ dishes with pricing and descriptions.
  - Search by dish or ingredient name.
  - Dietary toggles: Vegetarian, Non-Vegetarian, Chef's Specials, Spicy.
  - Sticky category navigation bar.
- **Corporate Dining & Packages (`/corporate`)**:
  - Official multi-course package breakdown:
    - **Vegetarian Package**: ₹1,299 + taxes per person (Min. 20 pax)
    - **Royal Non-Veg Package**: ₹1,599 + taxes per person (Min. 20 pax)
  - **Interactive Package Cost Estimator** with instant subtotal and 5% GST calculation.
  - Dedicated corporate lead capture form.
- **Celebrations Page (`/celebrations`)**: Milestone occasions and dedicated inquiry form.
- **Photo Gallery (`/gallery`)**: High-res categorized visual tour with interactive Lightbox.
- **Conversion & Direct Booking Systems**:
  - Global Table Reservation modal with WhatsApp confirmation and phone fallback (`085952 62617`).
  - Floating WhatsApp concierge with 4 pre-filled conversation intents.
  - Mobile bottom navigation bar (Menu, Call, WhatsApp, Reserve).
- **SEO & Schema.org JSON-LD**:
  - Structured data for `Restaurant` and `LocalBusiness` with coordinates (`28.5355, 77.3910`).
  - Dynamic `sitemap.xml` and `robots.txt`.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm 9.x or higher

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Build
```bash
npm run build
npm run start
```
